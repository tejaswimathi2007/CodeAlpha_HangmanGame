# 🎮 Hangman Game (Python)

## 📌 Project Description
This is a simple text-based Hangman Game built using Python. The program randomly selects a word, and the user tries to guess it letter by letter within limited attempts.

## 🚀 Features
- Random word selection
- User input handling
- Tracks used letters
- Limits incorrect attempts to 6
- Displays win/lose result

## 🛠️ Technologies Used
- Python
- Random module
- Loops and condition statements

## ▶️ How to Run
1. Install Python
2. Open terminal
3. Run:
   python hangman.py
